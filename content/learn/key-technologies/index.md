# Key technologies

The tools that show up in most designs, and how to use them in an
interview: what each is good at, its limits, and when to reach for it.

- [Redis](redis.md): in-memory cache, counters, leaderboards, locks and pub/sub.
- [Kafka](kafka.md): a durable, partitioned log for events and streams.
- [PostgreSQL](postgresql.md): the default relational database, and how far it scales.
- [DynamoDB](dynamodb.md): a managed key-value store with predictable latency.
- [Cassandra](cassandra.md): a wide-column store for heavy write loads.
- [Elasticsearch](elasticsearch.md): full-text search and filtering.
- [Blob storage and CDN](blob-storage-and-cdn.md): storing large files and serving them close to users.
- [API gateway and load balancer](api-gateway-and-load-balancer.md): routing, auth and rate limits at the edge.
- [Flink](flink.md): stateful stream processing.
- [ZooKeeper and etcd](zookeeper-and-etcd.md): coordination, leader election and configuration.
